灵动岛 横幅 倒计时窗口

灵动岛透明度设为 0 时完全隐身（不拦截触摸）。

新通知弹出时小岛展开显示标题与内容，滑动即可收起；连续通知可一键「免打扰至下课」。

默认窗口为横幅：无操作达到秒数后展开；有操作（移动鼠标/触摸）时收成灵动岛；全屏状态下始终维持灵动岛并鼠标穿透。

非全屏、非最大化状态下，无操作达到秒数后自动弹出倒计时窗口（纯展示、鼠标穿透，动一下即收回）。

只需每天的上下课时间（无课程名）；休息周/非课时免打扰按 45 分钟兜底。

自动关机任务可随时取消：提醒与关机倒计时通知上都有「取消关机」按钮，取消后当天不再触发。
