# ⏳ Smart Counter Island

面向**希沃教学大屏 / Windows 10/11** 的高考·中考·期末考倒数日程序。
普通状态下是一个悬浮在屏幕顶端、类似 **iOS 灵动岛**的小窗，带 **liquid glass（液态玻璃）** 质感；
支持智能隐藏、透明度管理、闲置自动放大，托盘常驻，双击托盘图标打开配置窗口。

> 完全离线可用、零运行时依赖、零原生编译（无需 Visual Studio / node-gyp）。
> 已实测：开发运行 ✅ · win-unpacked ✅ · 便携版 exe ✅ · NSIS 安装包 ✅（均为 Windows 11 + Win10 兼容）

## 🚀 快速开始（开发运行）

需要 Node.js 18+（本机已验证 Node 24）。

```powershell
npm install
npm run start        # 直接运行（出现顶部灵动岛 + 右下角托盘图标）
```

> 国内网络：`npm install` 前建议先设置镜像，见下文「国内网络加速」。

## 📦 打包成 exe

```powershell
npm run dist
```

`dist` 依次执行三步（无需人工干预）：

1. `electron-builder --win dir` —— 生成 `release/win-unpacked/`（解包目录）
2. `node scripts/rcedit-exe.js` —— 用 `build/rcedit-x64.exe` 给主程序写入图标与版本信息
3. `electron-builder --win --prepackaged release/win-unpacked` —— 生成安装包与便携版

产物在 `release/` 目录下：

- `SmartCounterIsland-Setup-1.1.0.exe` —— 安装版（开始菜单/桌面快捷方式，可选安装目录）
- `SmartCounterIsland-1.1.0-portable.exe` —— 绿色便携版（拷贝到任何 Win10/11 电脑**直接双击运行**，无需安装）

> 便携版已内置全部依赖（含 PowerShell 探针脚本），目标电脑**无需安装 Node 或任何运行库**。
> 打包默认跳过代码签名（无证书），Windows 可能提示「未知发布者」，点「更多信息 → 仍要运行」即可。
> 快速调试可只用 `npm run pack`（只出 win-unpacked 目录）。

## 🖥️ 使用说明

### 小岛手势（鼠标 / 希沃触摸屏通用）

| 操作 | 效果 |
| --- | --- |
| 单击小岛 | 细条 ↔ 放大版灵动岛（最大窗口时收起） |
| 双击小岛 | 打开配置窗口 |
| 按住向下拖拽 | 放大（最大窗口，保持 6 秒不被打扰） |
| 按住向上拖拽 | 缩小（回到细条） |
| 最大窗口底部按钮 | 📌 固定/自动 · ⚙ 配置 · ⋯ 菜单 · ▲ 收起 |
| 右键小岛 | 弹出菜单（模式切换 / 放大 / 配置 / 退出） |
| 触摸屏幕顶部细条 | 唤起小岛 |

> 三种状态（细条/放大版灵动岛/最大窗口）的位置**只能在配置窗口设置**（顶部居中/居左/居右或自定义坐标），小岛不再支持拖动移动（防止教学时误触）。

### 托盘图标

- **双击** → 打开配置窗口
- **单击** → 显示 / 隐藏小岛
- **右键** → 快速菜单

### 配置窗口（五个页签）

- **倒计时事件**：添加/编辑/删除（名称、目标时间、emoji 图标、强调色、启用状态）
- **显示效果**：玻璃模式（含「关闭=黑底白字」）、文言文开关、三种状态窗口各自的位置、显示器、透明度、置顶、显示时分秒、显示过期事件
- **智能行为**：智能总开关、全屏自动隐藏、最大化保持灵动岛、闲置切换秒数、事件轮播、手动模式
- **时间表**：周一~周日各天的上下课时间段（＋添加/删除）；「几周一休」N → N 周循环、第 N 周为休息周（不显示课表）；
  复制采用**两次点击**交互：点「📋 复制此天/此周」→ 点任意目标天/周完成（按日支持跨周，休息周不可作目标）；
  第 1 周可**一键复制到所有周**
- **关于**：操作提示与版本信息

## ⚙️ 工作原理（技术要点）

- **技术栈**：Electron 33 + 原生 HTML/CSS/JS，**零运行时依赖、零原生模块**。
- **全屏/输入检测**：常驻 `powershell.exe` 探针子进程（Win32 API：
  `GetForegroundWindow` / `GetWindowRect` / `GetCursorPos` / `GetLastInputInfo`），每 350ms
  汇报前台窗口矩形、光标位置与最后输入时间 —— 无需任何编译，Win10/11 原生自带 PowerShell。
  真全屏（盖住任务栏）才算「全屏授课」，最大化窗口不会误触发。
- **智能状态机**：`灵动岛 / 横幅 / 倒计时窗口` 三态（各有显示名称），主进程统一决策（纯函数可单测）。
  决策逻辑：**默认窗口 = 横幅**（固定不可更改）；无操作（闲置 `expandIdleSec` 秒）→ 横幅，
  有操作 → 灵动岛；**没有计时时间（无有效事件）→ 锁定灵动岛**，仅手动下滑手势可展开倒计时窗口；
  **全屏遮挡 → 维持灵动岛 + 鼠标穿透（不可唤起，手势/菜单放大均禁用）**；手动隐藏 → 灵动岛（触摸/悬停顶部可唤起）；
  前台窗口**最大化** → 保持灵动岛；倒计时窗口仅通过交互（拖拽/菜单）触发。
  自动切换带 1 秒去抖 + 光标悬停滞回 + 手动操作保持期（放大后 6 秒内不被自动切换打扰）。
- **真实毛玻璃（无重影）**：窗口创建时通过 `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` 让系统截屏
  自动排除小岛自身（Win10 2004+），再 `desktopCapturer` 截取背景 → `blur()` 叠加；细条（默认形态）强制无效果。
  每轮截屏同时计算小岛背后区域平均亮度，驱动文字颜色自动适配（深/浅）与「无效果模式」的白边判断。
- **DPI 缩放适配**：圆角命中区域（`SetWindowRgn`）按显示器缩放系数换算为物理像素，且 `CreateRoundRectRgn`
  的椭圆参数为 **2×CSS 圆角半径**，区域**外扩 3px**（Win32 区域边缘无抗锯齿，外扩后锯齿藏在 CSS
  平滑圆角之外的透明区，视觉无锯齿）；动画期间用超大矩形占位，避免旧区域裁剪造成"白边/残影"闪烁；
  探针的物理像素坐标按光标所在显示器缩放换算为 DIP。
- **探针脚本纯 ASCII**：`win-probe.ps1` 保持纯 ASCII 注释——PowerShell 5.1 对无 BOM 脚本按系统 ANSI（中文系统为 GBK）读取，
  含中文注释的 UTF-8 脚本在中文系统上会解析失败（已修复，任何区域设置均可用）。
- **系统通知接管**：探针进程（`-Sta` 模式）每约 1.75 秒枚举 ShellExperienceHost 通知窗口（Toast），
  并且**每轮枚举所有可见的置顶小窗**（尺寸 100–720×40–520、非全屏、非自身进程、非系统外壳，
  如 QQ NT / 微信 / 钉钉的通知气泡），通过 **UI Automation** 读取标题与内容；
  窗口的「矩形+标题」指纹变化（含同一窗口内容更新）才重新读取文本——避免每轮都做昂贵的 UIA 读取，
  同时兼容 QQ NT 复用同一气泡窗口的情况；主进程按 hwnd+文本双重去重，识别"新通知"后展开黑底白字
  通知形态并保持 `notifyShowSec` 秒；**展示框自适应**：渲染器按字体与内容测量（宽 280–560px、
  正文最多 2 行）上报尺寸，主进程动态调整窗口与圆角区域；滑动立即收起；连续通知时提供
  「免打扰至下课」——按时间表计算当天
  当前时段的下课时间（多周循环按 ISO 周号取对应周课表，休息周/无时间表/非课时按 45 分钟兜底），
  免打扰期间新通知自动屏蔽、到期自动恢复。
- **全屏鼠标穿透**：前台真全屏（盖住任务栏）时细条自动开启 `WS_EX_TRANSPARENT`（点击/触摸直接穿透到
  全屏应用），悬停顶部或唤起展开后自动恢复交互；通过 `%TEMP%\sci-transparent-cmd.txt` 命令文件交给
  探针执行 `SetWindowLongPtr`，与圆角区域同一套机制。
- **时间表数据**：`weeks` 为多套周课表（`cycleWeeks` 套，每套 7 天、每天为 `{start,end}` 时段列表），
  无课程名、无日期；旧版带课程名的 7 天数据启动时自动迁移；跨午夜时段（结束早于开始）按次日计算下课时间。
- **黑边/锯齿修复**：黑底形态（细条/无效果/通知）不使用外部投影、也不用大内阴影——两者都会超出
  圆角命中区域被 Win32 硬切，产生沿区域边缘的"黑边/不规则边界"；只用 1px 细描边，
  配合区域外扩 3px 后圆角完全平滑无黑边。
- **鲁棒性**：探针崩溃自动重启 · 通知解析失败降级 · 通知显示超时强制回退 · 免打扰到期自动恢复 ·
  时间表数据校验容错 · 渲染进程崩溃重建 · 显示器增删/分辨率变化自动重定位 · 玻璃截屏失败自动回退 ·
  单实例锁 · 动画期间暂停轮询与截屏 · 设置损坏恢复默认。
- **自检命令**：`--test` 全功能自动化测试（79 项断言，T1–T11；自检模式下探针喂中性快照，
  真实桌面状态不干扰断言），`--smoke` 冒烟（探针/毛玻璃/配置窗口）；均使用隔离的 userData。
- **打包**：`electron-builder` 直接使用本地 `node_modules/electron/dist`（免下载 Electron），
  `signAndEditExecutable: false` 跳过签名与 rcedit（规避无管理员权限时 winCodeSign 符号链接解压失败），
  再由 `build/rcedit-x64.exe` 事后写入图标与版本信息。

## 📁 项目结构

```
├─ package.json               # 依赖与 electron-builder 打包配置（含 dist 三步脚本）
├─ scripts/
│  ├─ gen-icons.js            # 纯 Node 生成图标（PNG/ICO，无需图像库）
│  └─ rcedit-exe.js           # 给 exe 写入图标与版本信息
├─ build/                     # 打包资源：icon.png / icon.ico / rcedit-x64.exe
└─ src/
   ├─ main/
   │  ├─ main.js              # 入口：托盘 / IPC / 生命周期 / 冒烟自检
   │  ├─ island.js            # 灵动岛窗口 + 智能状态机 + 截屏毛玻璃
   │  ├─ config.js            # 配置窗口
   │  ├─ probe.js             # PowerShell 探针子进程管理（自动重启）
   │  ├─ win-probe.ps1        # Win32 系统探针脚本（extraResources 随包分发）
   │  └─ settings.js          # 设置持久化（%APPDATA%\SmartCounterIsland\settings.json）
   ├─ preload/                # contextBridge 安全桥
   └─ renderer/
      ├─ island/              # 灵动岛界面（HTML/CSS/JS）
      └─ config/              # 配置界面
```

## 🔧 常见问题

- **小岛不出现 / 卡成细条**：检查托盘图标（右下角 ⏳）；单击托盘图标切换显示；触摸屏幕顶部即可唤起。
  检查「智能行为 → 启用智能行为」与「手动模式」是否为「自动」。
- **全屏时不隐藏**：确认「全屏授课自动收细条」已开启；个别非标准全屏窗口可能检测不到（判断标准：窗口盖住任务栏区域）。
- **配置窗口打不开/被遮挡**：配置窗口已设为最高置顶层级，不会被小岛（尤其放大态）盖住；窗口右上角还有「✕ 关闭」按钮。
- **编辑弹层关不掉**：已修复（弹层 `hidden` 属性被 `display:flex` 覆盖的问题），点「取消/保存」均可正常关闭。
- **窗口"跳舞"（反复跳动/切换）**：已加 1 秒去抖 + 光标悬停滞回，边界抖动不再触发反复切换。
- **窗口有方形透明层**：已改为 Win32 圆角命中区域（`SetWindowRgn`），圆角外完全不绘制、不拦截输入。
- **字体不清晰**：已开启抗锯齿渲染并加大加粗数字；如仍不满意可将「玻璃效果」改为「模拟玻璃」（真实模糊下文字对比略低）。
- **毛玻璃是模拟的**：低配机器可将「玻璃效果」改为「模拟玻璃」或「关闭」。
- **Windows 提示未知发布者**：程序未做代码签名（需要付费证书），属正常现象。
- **npm 24 安装 Electron 不完整**：新版 npm 默认拦截包安装脚本，`npm install` 后 `node_modules/electron/dist/electron.exe`
  可能不存在。执行 `npm approve-scripts electron` 后重新 `npm install`，或手动运行：
  `$env:ELECTRON_MIRROR="https://npmmirror.com/mirrors/electron/"; node node_modules/electron/install.js`。
- **设置文件位置**：`%APPDATA%\SmartCounterIsland\settings.json`，可直接编辑后重启程序；
  从旧版（Liquid Glass Counter）升级时设置会自动迁移。
- **自检命令**：`npm run smoke`（或对打包产物 `xxx.exe --smoke`）验证探针 / 毛玻璃 / 配置窗口，输出 `SMOKE_OK` 退出；
  `npm run test`（或 `xxx.exe --test`）运行 79 项全功能自动化测试，输出 `TEST_OK` 退出。
